# 🛍️ Shopping Behavior Analysis

## 📊 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, and key factors influencing shopping decisions.

The project uses **Python, SQL, and Power BI** to clean, analyze, and visualize customer shopping data and generate meaningful business insights.

---

## 🎯 Objectives

- Analyze customer purchasing behavior
- Identify customer preferences and shopping patterns
- Understand purchasing frequency and spending behavior
- Analyze customer demographics
- Identify popular product categories
- Analyze discounts and subscription behavior
- Generate actionable business insights
- Build an interactive Power BI dashboard

---

## 🛠️ Tools & Technologies

- **Python** – Data Cleaning & Exploratory Data Analysis
- **Pandas** – Data Manipulation
- **NumPy** – Numerical Analysis
- **Matplotlib** – Data Visualization
- **Seaborn** – Statistical Visualization
- **SQL** – Data Analysis & Business Queries
- **Power BI** – Interactive Dashboard
- **Jupyter Notebook** – Analysis Environment
